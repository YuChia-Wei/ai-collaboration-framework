# Technical Description template

Use the [shared contract](../story-contract.md) and separate Title/AC fields.
For research, adapt the objective to a learning question and outcome to evidence;
retain time/scope bound, stopping criterion and decision owner, unknown if absent.

## Technical Objective
Identify the independent technical value or learning outcome and beneficiary.

## Current State and Problem
Describe source-backed state, problem and evidence limitations.

## Expected Outcome
State a measurable outcome and preserved outward behavior where relevant.
Use supplied measures; mark absent thresholds unknown instead of choosing numbers.
Research promises an evidence output, not production success.

## Technical Requirements and Constraints
Keep supplied TR IDs (or explicitly proposed local labels), versions, architecture
and deployment constraints. Include an approach only if accepted or marked proposed.
Do not prescribe infrastructure from the template alone.

## Scope
Define the technical/learning boundary and exclusions, including research bounds.

## Open Questions
List unresolved decisions and impact; omit when empty.
