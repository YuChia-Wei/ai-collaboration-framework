# A8 實際輸出

採用已安裝的 test-designer@0.4.0／design，以 GWT scenario notes 表達本次已接受規則。行為來源為本次 A8 提示中的 R1／AC1：「另一位會員預約借閱品時拒絕續借且到期日不變」。來源狀態為呼叫者明示已接受，未提供另一本文件或版本號。

本地 scenario ID：LOCAL-A8-RENEWAL-RESERVED-01。此 ID 僅識別本案例，不取代 R1／AC1。

- **Given**：Ada 持有借閱紀錄 L7，原到期日為 10/20；Ben 是另一位會員，已預約 L7 對應的同一借閱品。本案例獨立建立上述狀態，不依賴其他案例先執行。
- **When**：Ada 對 L7 提出一次續借請求。
- **Then**：可觀察的續借結果為拒絕。
- **And**：請求完成後，L7 的到期日仍為 10/20。

R1／AC1 對應 LOCAL-A8-RENEWAL-RESERVED-01 的拒絕結果及到期日保留兩項觀察。兩者皆由已接受 R1／AC1 提供獨立預期值，不能只檢查拒絕便視為日期未變，也不能從待測續借演算法推導預期值。

最小可觀察斷言為：續借回應呈現拒絕；透過選定業務或公開讀取介面再次取得 L7，到期日等於請求前保存的 10/20。具體結果欄位、錯誤碼或 HTTP 狀態未提供，暫不指定。10/20 的年份、時區及日期型別仍需測試設施確認，不能自行補值。

建議以應用操作邊界設計這項檢查，涵蓋續借結果及操作後可見的借閱狀態；這是規劃中的測試層級，目前未證實目標具備可執行設施。待確認設施包括：建立 Ada／Ben、L7 及同一借閱品預約的隔離 fixture；續借呼叫入口與會員身分控制；拒絕結果的可觀察契約；操作完成及狀態重新讀取機制；日期與時鐘控制；案例資料隔離與清理。若預約來源透過受控 port 提供，僅能支持應用邊界行為，真實預約 adapter 的互動需另外選定整合設施。
