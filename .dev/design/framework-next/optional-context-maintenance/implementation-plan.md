### Metadata contract to implement, not a specimen claiming implementation

Both packages use metadata_version exact integer 3, proposed package version 0.1.0,
entrypoint SKILL.md, empty required/optional dependencies, configuration null,
empty artifact_roles, schemas, templates and tools. Each declares one own method
in resources.references. Runtime is skill-instruction-reader with on_missing
unavailable, scoped to its own operations. All operations use execution instruction
and instructions referencing that method; no tool arm. Inputs/outputs follow the
[operation table](operations-and-handoffs.md). Set delivery/implementation status
implemented only when the source entry, metadata and method actually exist.
Instruction delivery does not claim invocation, installation or verification.

No new schema, record version, config namespace, mechanical finalizer, migrator,
query store, shared runtime, dependency resolver or legacy-format converter belongs
to I1/I2. Package version evolution owns instruction changes; target records remain
with their selected format/version owner. Unsupported project formats stay intact.
