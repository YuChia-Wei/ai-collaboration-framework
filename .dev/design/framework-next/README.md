# Framework-next historical design

This directory preserves the 2026 redesign program (#322), selected contracts,
inventories and stage records. It is historical design evidence, not a current
execution entry. Counts, package names, paths, CI status and proposed operations
describe their recorded revisions; they do not establish current availability.

- [Product source](../../../src/readme.md) and [distribution manifest](../../../src/distribution/manifest.yaml).
- [Source development policy](../../standards/SOURCE-DEVELOPMENT-POLICY.md).
- [Domain/software split and follow-up design](../skill-evolution-2026-10-22/README.md).

Selected historical contracts remain evidence for compatibility and actual
retained U001, release, support and recovery duties. Those duties require their
compatible revision and verified route; this landing page neither retires them
nor marks deferred validation passed. Original documents and inventories remain
in place. A later proposal must identify exactly which current responsibility
would change before claiming that an older decision has been superseded.
